# BDC Analytics Dashboard

A beautiful, interactive Streamlit dashboard for analyzing Business Development Companies (BDCs).

## Features

### 📈 Overview Tab
- **BDC Selector**: Choose any BDC from the dataset
- **Key Metrics**: Total Assets, Net Assets, Net Investment Income, Forecast
- **Historical Trends**: Interactive charts showing assets and income over time
- **Leverage & Efficiency**: Debt ratios, NII to assets, debt to equity
- **Forecast Details**: Next quarter prediction with projected values

### 💼 Portfolio Tab
- **Portfolio Characteristics**: Fair value vs cost, concentration metrics
- **Rate Type Distribution**: Floating vs fixed rate exposure
- **Sector Exposure**: Top sector weights
- **Valuation Gap**: Fair value - cost gap analysis

### ⚖️ Compare Tab
- **Multi-BDC Comparison**: Compare 2-5 BDCs side-by-side
- **Comparison Table**: Key metrics in tabular format
- **Historical Charts**: Overlayed trends for selected BDCs

### 🤖 Model Performance Tab
- **Model Comparison**: Performance metrics for all models
- **Best Model**: Automatically identifies top performer
- **Visualizations**: MAE and R² comparisons
- **Backtest Results**: Historical prediction statistics

## Running the Dashboard

### Prerequisites

Install required packages:
```bash
pip install streamlit plotly pandas
```

Or install all requirements:
```bash
pip install -r requirements.txt
```

### Launch Dashboard

From the project root:
```bash
streamlit run dashboards/streamlit_app.py
```

Or use the provided script:
```bash
python scripts/run_dashboard.py
```

The dashboard will open in your default web browser at `http://localhost:8501`

## Data Requirements

The dashboard requires the following data files (generated by the pipeline):

- `data/processed/bdc_feature_panel.parquet` - Feature panel with all metrics
- `data/processed/bdc_quarterly_panel.parquet` - Quarterly panel data
- `data/processed/bdc_entity_reference.parquet` - BDC entity reference
- `data/processed/forecasts.parquet` - Latest forecasts
- `data/processed/models/model_comparison.csv` - Model performance metrics
- `data/processed/models/backtest_predictions.parquet` - Backtest results

If any files are missing, run the data pipeline:
```bash
python -m src.data.panel
python -m src.features.feature_engineering
python -m src.models.train
python -m src.models.predict
```

## Customization

### Adding New Metrics

Edit `dashboards/streamlit_app.py` and add new metric displays in the appropriate tab functions.

### Changing Colors

Modify the color schemes in the Plotly chart configurations or update the CSS in the `st.markdown()` sections.

### Adding New Tabs

1. Create a new render function (e.g., `render_new_tab()`)
2. Add it to the `st.tabs()` call in `main()`
3. Call the render function in the appropriate `with tabX:` block

## Troubleshooting

### Dashboard won't start
- Ensure Streamlit is installed: `pip install streamlit`
- Check that all data files exist in `data/processed/`

### No data showing
- Verify data files are not empty
- Check that the pipeline has been run successfully
- Look for error messages in the Streamlit console

### Charts not displaying
- Ensure Plotly is installed: `pip install plotly`
- Check browser console for JavaScript errors

## Notes

- All data is cached using `@st.cache_data` for performance
- The dashboard automatically uses the latest period in the data
- Forecasts are generated using the best-performing model (lowest MAE)
